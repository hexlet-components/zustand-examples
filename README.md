Примеры к [курсу Zustand на Хекслете](https://ru.hexlet.io/courses/js-zustand). Каждый каталог содержит отдельное React-приложение на Vite.

## Примеры

| Каталог | Содержимое |
| --- | --- |
| _starter_ | Минимальное React-приложение для выполнения примеров урока. Zustand ещё не подключён |
| _first-store_ | Готовый пример урока «Первый стор». Счётчик и кнопки работают с общим состоянием |

## Запуск

Установите Node.js 26 и pnpm 11. Из каталога репозитория установите зависимости и запустите стартовое приложение.

```bash
pnpm install --frozen-lockfile
pnpm --dir starter dev
```

Откройте адрес, который Vite напечатает в терминале. Чтобы начать работу со стором по уроку, остановите сервер и установите Zustand в стартовое приложение.

```bash
pnpm --dir starter add zustand
```

Готовый пример запускается отдельно.

```bash
pnpm --dir first-store dev
```

## Проверки

Сборка и линтер проверяют оба приложения. Браузерные тесты проверяют загрузку стартового приложения, изменение и сброс счётчика.

```bash
pnpm build
pnpm lint
pnpm exec playwright install chromium
pnpm test
```
